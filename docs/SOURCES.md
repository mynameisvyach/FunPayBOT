# Происхождение компонентов

[← FunPay BOT](../README.md) · [Руководство](GUIDE.md)

FunPay BOT v1.60 использует локальную копию FunPayAPI из [FunPayCardinal](https://github.com/sidor0912/FunPayCardinal/tree/c09dd13be25072bb3d5cdbba33d1e0d70e477710/FunPayAPI): тег `v0.1.17.15`, commit `c09dd13be25072bb3d5cdbba33d1e0d70e477710`.

Исходники `vendor/FunPayAPI` не изменяются при обновлении оболочки. `vendor/revision.txt` содержит commit, а `vendor/api-lock.json` — SHA256 Python-файлов. При запуске проверяется именно эта локальная копия; изменяемая ветка репозитория не скачивается.

Фреймворк расширений развивает идею UnifiedAutomation: общие жизненный цикл, настройки, маршрутизация, состояние и торговые операции находятся в ядре. Расширение добавляет правила товара и взаимодействие с поставщиком. Публичный релиз не содержит расширений конкретных поставщиков.

Общий обработчик цен развивает механизм AutoDump; он работает с профилями обычных лотов и `chips`. Инструменты импорта, экспорта и создания серий являются частью ядра, а не отдельным плагином.

Сторонние библиотеки подключаются из `requirements.txt`. Их авторство и условия распространения сохраняются за соответствующими авторами; этот документ не меняет лицензии стороннего кода.
