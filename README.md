Бот объединяет работу с аккаунтом FunPay в одной Telegram-супергруппе с темами. Управлять им может владелец, указанный в настройках. Текстовые сообщения также принимаются от имени самой настроенной группы — для анонимного администратора. В личных сообщениях бот не работает.

## Возможности

| Раздел | Что доступно |
| --- | --- |
| Переписка | Отдельные темы покупателей, отправка текста и изображений, сообщения системы и поддержки, кнопки заготовок продавца |
| Заказы | Карточки статусов, отметка выполнения, возврат с подтверждением, история в Telegram, обработка позднего возврата |
| Автоматизация | Приветствия, ответы по точным командам, напоминания, ответы на отзывы, отметка последней активности продавца |
| Лоты | Встроенные экспорт, импорт, перенос, удаление и создание серии обычных лотов из шаблона |
| Финансы | Баланс, поступления, себестоимость при её наличии, комиссии, задержка доступности средств, предварительный расчёт, ручной и автоматический вывод |
| Уведомления | Отдельные переключатели событий, рыночные курсы CoinGecko, отчёты |
| Обслуживание | Прокси Telegram и FunPay, смена `golden_key`, перезапуск, ручная выгрузка и загрузка резервного ZIP |
| Расширения | Общий SDK, объявления зависимостей, настройки и управляемые фоновые задачи |

**Плагины в поставку не входят.** Инструменты лотов встроены в ядро. Автоматическая покупка у поставщика и выдача конкретного товара появляются только при установке соответствующего собственного расширения. Общий обработчик изменения цен для `common` и `chips` доступен расширениям через SDK.

## Начать работу

1. Распакуйте релиз или скачайте содержимое репозитория.
2. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather). Добавьте его администратором в супергруппу с включёнными темами и разрешите управление темами, закрепление и удаление сообщений.
3. Запустите `bash start.sh` на Linux или `start.bat` на Windows.
4. Заполните установщик: токен бота, ID группы, ID владельца, FunPay `golden_key` и User-Agent. Либо заранее замените `YOUR-*` в `config.json`.
5. Отправьте `/menu` в настроенной группе.

Зависимости проверяются отдельно от настроек. Если пакетов нет, бот устанавливает их в локальное окружение; заполненный конфиг из-за этого не сбрасывается. Сначала подготавливаются включённые плагины, затем запускаются их рабочие задачи.

## Настройки и руководство

В `config.json` уже заполнены нейтральные примеры приветствий, отзывов, напоминаний и заготовок. Автовывод, автотикеты и автоподнятие по умолчанию выключены. Подставьте собственные доступы и включите нужные функции через меню «Автоматизация».

[Полное руководство →](docs/GUIDE.md) содержит установку, описание всех разделов конфига, переменные шаблонов, встроенные инструменты лотов, финансы, журналы и пример собственного плагина.

`main.py` содержит версию проекта и точку запуска. Код ядра находится в `funpay_bot/`, публичный интерфейс расширений — в `unified_sdk.py`, файлы расширений устанавливаются в `plugins/`.

В репозитории должен оставаться шаблон `config.json` с `YOUR-*`. Рабочие ключи, настроенные конфиги и каталог `data` предназначены для личной установки.

## Зависимости

- Python **3.11+**; рекомендуемая версия для новой установки — **3.12**.
- Windows или Linux; доступ к Telegram, FunPay и индексу пакетов для первой установки. Для курсов используется CoinGecko.
- FunPayAPI: закреплённая копия **v0.1.17.15**, commit `c09dd13be25072bb3d5cdbba33d1e0d70e477710` из FunPayCardinal.
- Точные версии пакетов находятся в [requirements.txt](requirements.txt) и [в конце подробного руководства](docs/GUIDE.md#зависимости). Дополнительные пакеты расширений объявляются самими расширениями.
